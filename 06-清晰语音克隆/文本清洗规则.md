# 文本清洗规则 · 让 F5-TTS 不出「怪音」

> F5-TTS 是**逐字模型**。它念出的怪音（「嘟噜」「吧」「a憨」等），
> **几乎都不是模型或音质问题，而是文本里有它词表外的字符**。
> 本文给出完整清洗规则与校验方法。

---

## 一、三类必须清洗的字符

### 1. 阿拉伯数字 → 汉字

F5 的数字 token 无法映射到中文数词读音，多位数会**逐位乱读**。

| 原文 | 实际念成 | 改成 |
|---|---|---|
| `99块` | 「纳尼那」 | `九十九块` |
| `800条` | 「a憨字条」 | `八百条` |
| `2024年` | 乱读 | `二零二四年` |

**规则**：文案里**所有** `0-9` 一律换成汉字。小数、百分比、金额同理（`3.5%`→`百分之三点五`）。

### 2. 全角标点 → 半角或逗号

实测：F5 词表里**没有全角冒号 `：`**（`；`、`（）` 也没有）。
不在词表 → F5 映射到垃圾 token → 念出「吧」这类怪音。

| 字符 | 在词表? | 处理 |
|---|---|---|
| `：` 全角冒号 | ❌ 不在 | → `，` |
| `；` 全角分号 | ❌ 不在 | → `，` |
| `（）` 全角括号 | ❌ 不在 | → 删除或改 `，` |
| `——` 破折号 | ✅ 在，但渲染不稳 | → `，` |
| `""` 中文引号 | ✅ 在，但无语音价值 | → 删除 |
| `，。？！、` | ✅ 在 | 保留 |

### 3. 其他

- **拉丁字母**：尽量少用。必须用时（如品牌名）注意其读音可能不自然，建议直接写成中文音译。
- **表情、特殊符号、换行符**：全部删除。
- **多空格**：合并成一个。

---

## 二、清洗后必须校验（关键）

清洗完**不能凭感觉**，必须逐字符核对：**非 CJK 字符必须全部在 `vocab.txt` 里**。

**词表路径**：

```
<F5-TTS安装目录>\venv\Lib\site-packages\f5_tts\infer\examples\vocab.txt
```

**一键校验**：

```bat
venv\Scripts\python.exe scripts\clean_text.py 你的文案.txt
```

脚本逻辑：
1. 自动做上述清洗（数字转汉字、标点替换）；
2. 遍历每个字符 —— CJK 汉字天然 OK（走拼音路径）；
3. **非 CJK 字符逐个查 `vocab.txt`**，报告任何仍不在词表内的字符。

输出示例：

```
[清洗] 99块 -> 九十九块
[清洗] ： -> ，
[校验] 剩余非词表字符：无 ✅
```

若报告仍有字符，手动处理后再跑一次。

---

## 三、校验脚本的判定逻辑（供 AI 参考）

```python
def is_cjk(c):
    o = ord(c)
    return (0x3400 <= o <= 0x9FFF) or (0xF900 <= o <= 0xFAFF) or (0x20000 <= o <= 0x2FA1F)

vocab = set(open(vocab_path, encoding="utf-8").read().split("\n"))
bad = {c for c in text if not c.isspace() and not is_cjk(c) and c not in vocab}
```

`bad` 必须为空集。

## 四、一个反例（真实踩坑）

原句：

```
你花99块买的课，和收藏夹里那800条赚钱视频……大脑很会偷懒：……
```

F5 念出：

> 「你花**纳尼那**买的课……那**a憨字条**……大脑很会偷懒**吧**」

三处怪音，分别对应 `99`、`800`、`：`。
清洗为：

```
你花九十九块买的课，和收藏夹里那八百条赚钱视频……大脑很会偷懒，……
```

重新生成后 ASR 逐句核对，全部正确。

---

## 五、一句话总结

> **看到怪音，先查文本，别怀疑模型。**
> 数字改汉字、全角标点改逗号、删引号，再用 `clean_text.py` 校验到「无剩余非词表字符」，即可根治。
